동일 잠금파일, 로컬 Vite 빌드 기준 메인 JS는 기존 약 2,131.42kB → 약 1,089kB(압축 전). 하위 페이지·포트폴리오·관리자 코드를 필요할 때 로드하도록 분리한 결과이며 총 다운로드량이나 LCP 개선 실측을 뜻하지 않는다.
