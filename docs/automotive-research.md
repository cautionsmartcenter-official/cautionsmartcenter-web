# 코션 리뉴얼 — 자동차 웹사이트 조사

조사일: 2026-10-15 (Asia/Seoul)

## 범위와 해석

- 공개 트래픽 순위와 공식 사이트의 정보·탐색 구성을 조사했다. 웹 텍스트 기준 조사로, 애니메이션 타이밍이나 실제 화면 대비를 측정한 결과는 아니다.
- 방문량 순위는 미국 자동차 분야의 상대 순위이며 한국 시공점 시장의 수요와 같지 않다. 브랜드 인지도, 재고, 검색 유입, 광고 등 영향을 분리할 수 없으므로 특정 디자인 때문에 방문자가 많다는 인과관계는 주장하지 않는다.
- 현재 사용자 요구: 기존 폰트, 구성, 모든 문구, 카카오·유튜브 및 연계 서비스를 보존한다. 아래 적용안은 해당 콘텐츠와 연결을 유지하며 표현·피드백·로딩을 개선하는 범위다.

## 2. 제조사 웹사이트 만족도 연구

### 최신 확인 자료: J.D. Power 2026 Summer

[공식 발표](https://jdpower.com/business/press-releases/2026-u-s-manufacturer-website-evaluation-study/), 2026-07-16. 미국 신차 구매 예정자 **11,388명**, 2026년 4~5월 조사. 1,000점 기준 고급 브랜드 **Porsche 779점**, Mercedes-Benz 770점, Infiniti 768점. 대중 브랜드 Dodge 740점, Hyundai 737점, Nissan 736점.

평가 요소는 내비게이션, 속도, 시각적 매력, 차량 정보 조사, 조사 도구 순이다. 연구는 명확한 가격 정보와 구매 검토의 관련성을 설명한다. 코션에서는 기존 상담·가격·공정 안내가 있다면 쉽게 찾게 만들되, 새 가격이나 근거 없는 효과를 만들지 않는다. 만족도 순위는 방문자 순위와 다르다.

### 정보와 효과의 균형

[2026 Winter 공식 발표](https://www.jdpower.com/business/press-releases/2026-us-manufacturer-website-evaluation-study-winter/)는 브랜드가 미정인 구매 예정자의 **94%**가 제조사 사이트를 찾으며, 구매 차종을 정한 사람도 **83%**가 사이트를 방문한다고 보고한다. 연구는 상세 제품 정보의 중요성을 강조한다.

[2025 Summer 공식 발표](https://jdpower.com/business/press-releases/2025-us-manufacturer-website-evaluation-study-summer)는 속도·일관된 디자인·정돈된 구성·현대적 외관의 기본 기대를 충족한 사이트의 만족도가 **752점**, 충족하지 못하면 **664점**이라고 보고한다. 자동 영상과 애니메이션은 외관을 개선해도 체감 속도를 늦출 수 있다는 설명도 있다. 이 수치는 특정 효과의 개별 인과 실험 결과로 해석하지 않는다.

## 3. 감성 표현을 참고할 공식 브랜드

### Lamborghini

[공식 홈페이지](https://www.lamborghini.com/en-en)에서 모델 선택 → 구성하기 → 문의의 흐름과 텍스트 크기·애니메이션 허용 제어가 확인된다. 코션에는 기존 차량 이미지·영상의 감상 구간을 강화하고 바로 이어지는 기존 상담 행동을 선명하게 드러내는 방식을 제안한다. 애니메이션은 제품을 보게 하는 역할에 집중한다. Lamborghini의 높은 방문량을 입증한 순위는 이번 자료에 없으므로 인기 순위 근거로 제시하지 않는다.

### Porsche

[공식 미국 홈페이지](https://www.porsche.com/usa/)는 대표 이미지 다음에 모델별 설명·시작 가격·탐색 행동을 일관되게 제공하고 센터 찾기·재고 탐색으로 연결한다. 코션에서는 기존 서비스 순서를 유지하면서 이미지·제목·설명·버튼 사이의 간격과 강조를 통일하는 방식을 참고한다. 대형 이미지와 구체적인 설명이 함께 존재하도록 하는 것이 핵심이다.

## 4. 이번 리뉴얼의 구체적인 적용 기준 (설계 제안)

1. **히어로:** 기존 영상과 문구를 유지한다. 제목은 바로 읽을 수 있게 표시하고 짧은 줄 단위 등장 효과를 한 번 적용한다. 문장 반복 교체·글자 흩어짐·긴 강제 로더는 쓰지 않는다.
2. **영상:** 포스터를 먼저 표시하고 로드 실패 시에도 내용을 유지한다. 화면 밖 또는 백그라운드 탭에서 멈추며, 자동 재생은 무음으로 시작한다. 재생·일시정지 상태를 명확히 표현한다.
3. **섹션:** 순서를 유지하며 작은 이동과 투명도 변화로 진입을 알린다. 기존 본문은 스크롤 애니메이션이 실패해도 읽을 수 있어야 한다.
4. **자막 느낌의 문구 효과:** 기존 문구를 그대로 사용한다. 시각적 마스크를 사용해도 스크린 리더에는 문장이 한 번만 전달되도록 한다. 실제 음성이 있는 영상의 접근성 자막과 장식적 제목 효과는 구별한다.
5. **카드와 버튼:** 기존 링크·핸들러·데이터를 유지한다. 호버 외에 키보드 포커스·눌림·선택 상태도 표시한다. 과한 확대보다 경계선·그림자·짧은 이동을 사용한다.
6. **가독성:** 기존 폰트 계열을 보존하며 본문 크기·줄 간격·대비와 모바일 줄바꿈을 확인한다. 장식 자막 때문에 본문을 작게 만들지 않는다.
7. **연동 서비스:** 카카오·유튜브·지도·전화·예약 등 기존 연결을 보존하고 목적지를 대조한다. 외부 서비스 데이터·인증정보는 새 프런트엔드에 노출하지 않는다.
8. **움직임 감소:** `prefers-reduced-motion`에서는 즉시 표시하고 영상 자동 재생·패럴랙스를 줄인다. 저성능 기기에서는 이미지 중심으로도 사용할 수 있어야 한다.

## 검증 항목

- 원본 대비 콘텐츠 문구, 폰트 계열, 메뉴·섹션 순서, 외부 링크와 호출 대상 보존.
- 모바일/데스크톱 가로 넘침, 이미지 선명도, 영상 미재생 상태, 키보드 탐색.
- 문의·영상·예약의 실제 버튼 동작. 발송·예약 등 외부 쓰기 검증은 실제 고객 요청을 만들지 않는 범위에서 수행.
- 애니메이션 전후 레이아웃 이동과 로딩 상태 확인. 성능 목표는 측정 결과 없이 달성했다고 주장하지 않음.

## 결론

대형 자동차 사이트에서 참고할 핵심은 탐색과 정보의 명확성이고, 프리미엄 제조사에서 참고할 핵심은 제품을 크게 보여주는 표현과 다음 행동의 연결이다. 코션은 기존 콘텐츠·서비스를 보존한 상태에서 이 두 가지를 결합한다. 체류시간이나 상담 전환 개선은 배포 후 분석 이벤트와 실제 이용 데이터로 확인해야 한다.
