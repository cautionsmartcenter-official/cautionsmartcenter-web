📦 1. 방금 생성해 둔 전송 파일
프로젝트 폴더 안에 

코션스마트센터_윈도우이동용.zip
 파일을 만들어 두었습니다.
(오류를 일으키는 node_modules는 빼고, 이미지/동영상/폰트/코드 및 윈도우 전용 실행기까지 모두 담겨 있습니다.)

👉 이 코션스마트센터_윈도우이동용.zip 파일 1개만 USB, 구글 드라이브, 카카오톡 등을 통해 윈도우 PC로 옮겨주세요.

💻 2. 윈도우 PC에서 똑같이 실행하는 순서
① 윈도우에서 압축 풀기
옮긴 압축 파일의 압축을 원하시는 위치(예: 바탕화면 또는 C:\projects\)에 풉니다.

② Node.js 설치 확인 (최초 1회만)
윈도우 PC에 Node.js가 깔려있지 않다면, nodejs.org에 들어가셔서 LTS 버전을 다운로드받아 설치해 주세요. (기본 설정 그대로 다음-다음 누르시면 됩니다.)



③ 윈도우실행.bat 더블 클릭!
압축 푼 폴더 안에 들어있는 윈도우실행.bat 파일을 더블 클릭합니다.
자동 진행 내용:
윈도우 환경에 맞는 모듈을 자동으로 설치합니다 (npm install).
로컬 개발 서버가 자동으로 시작됩니다 (npm run dev).
콘솔 창에 http://localhost:5173 주소가 뜹니다.
④ 브라우저 열기
인터넷 브라우저(크롬, 엣지 등)를 켜고 주소창에 http://localhost:5173 을 입력하고 접속하시면, 지금 맥에서 보시는 로컬 웹페이지와 100% 동일한 화면이 그대로 나타납니다!
이후에 코드를 수정하시면 맥에서처럼 윈도우 브라우저에서도 실시간으로 바로바로 반영됩니다. 진행하시면서 궁금하거나 막히는 점이 생기면 언제든 말씀해 주세요!
